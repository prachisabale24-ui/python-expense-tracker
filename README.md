# Python Expense Tracker 💰

A simple expense tracker built using Python that helps users record daily expenses, view saved expenses, and calculate total spending in Indian Rupees (₹).

## Features

- Add daily expenses
- View all recorded expenses
- Calculate total spending
- Save expenses to a text file
- Load previously saved expenses when the program starts
- Validate user input
- Handle invalid amounts
- Display expenses in Indian Rupees (₹)

## Technologies Used

- Python
- File Handling
- Exception Handling

## Python Concepts Used

- Variables and data types
- Lists and tuples
- `while` loop
- `if-elif-else` statements
- `try-except` error handling
- File handling (`open`, `read`, `write`)
- Working with file paths using `os`

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `python expense_tracker.py`

6. Choose an option from the menu.
7. Add expenses and view your total spending.

## Menu Options

1. Add Expense
2. View Expenses
3. Show Total Spending
4. Exit

## Data Storage

Expenses are saved in a file named `expenses.txt` in the same folder as the Python program. Previously saved expenses are loaded when the program starts.

**Note:** The `expenses.txt` file is created automatically when you add your first expense. Your personal expense data is not included in this repository.
